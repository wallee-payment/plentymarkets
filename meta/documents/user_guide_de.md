# Verbinden Sie Ihren Shop mit wallee

erbinden Sie Ihren PlentyONE-Shop mit wallee und greifen Sie über eine einzige Integration auf eine große Auswahl moderner Zahlungsmethoden zu.
Wählen Sie aus einem breiten Angebot an lokalen und globalen Zahlungsmethoden und nutzen Sie moderne Checkout-Optionen über die Zahlungsseite. Der Checkout kann individuell an Ihren Shop und Ihre Marke angepasst werden.

Zu den wichtigsten Funktionen gehören:

* PlentyONE PWA-Unterstützung (Progressive Web App) direkt aus der Box
* Nahtlose Migration zu PlentyONE PWA
* Erstellung Ihrer individuellen Rechnungsdokumente und Lieferscheine
* 3D Secure-Zahlungen
* Rückerstattungen direkt aus PlentyONE
* Unterstützung von Multi-Shop-Setups
* Zugang zum wallee-Portal mit Dashboards, Berichten und Exporten
* Omnichannel-Funktionen
* Automatische Mahnungen per Post mit unserer pingen.com-Integration
* Automatischer Dokumentendruck über die Cloud
* PCI DSS-Konformität
* Und mehr

## Voraussetzungen

Für die Nutzung des Plugins ist ein wallee-Konto erforderlich. Wenn Sie noch kein Konto haben, können Sie sich für ein Testkonto registrieren.
Das Plugin kann über den PlentyONE-Marketplace installiert werden.
Detaillierte Informationen zu Installation, Konfiguration, Zahlungsmethoden, Rückerstattungen, Anpassungen, PWA-Unterstützung und weiteren Funktionen entnehmen Sie bitte der Dokumentation von wallee.
